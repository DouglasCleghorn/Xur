XBOX CONTROLLER

Small movements. Direct control.

Pair your Xbox controller with the receiver connected to the robot. A steady Xbox light means pairing is complete. Keep sticks centered and release all buttons before starting.

Start a session

  1. Load the Robotics profile and select the controller and cameras in Robotics setup.
  2. Prepare the tools and complete approved calibration and motor limits. The dashboard explains any missing requirements.
  3. Stand beside the robot, clear its arms and keep a motor-power disconnect within reach.
  4. Select Start controller control on the dashboard. This starts a 60-second session.
  5. Hold Start / Menu to allow movement. Releasing it holds the current pose. Press Back / View to end the session.

Use E-STOP on any robot page to stop the session and latch motion off. After inspecting the robot, select Reset E-stop; reset checks fresh feedback from all seventeen motors and leaves the robot disarmed. Use Stop & disarm for an ordinary session end. If a joint behaves unexpectedly, disconnect motor power immediately.

Sessions end disarmed. This uses the pinned XLeRobot Xbox helpers with bounded steps, travel, following-error and motor-effort checks. Releasing Start holds position; ending the session disables torque, so an unsupported arm can settle.
