Keep your coding environment on the server.

T3 Code holds your projects, sessions and tools on the Xur machine. Pair the app on each device to return to the same work, even after a GPU profile change.

These screens show Nightly 26.11.014. If you have an older build, check your application update channel.

Pair your first device

  1. Open T3 Code in Xur and choose Install. The first start needs internet access. Leave Auto-run on to start T3 after a reboot.
  2. Install the T3 Code app on your phone or computer. Connect to the server’s LAN or tailnet. The app needs to reach the server on port 3773.
  3. In Xur, choose Create pairing link. Paste it into Add environment in the T3 app, or scan the QR code on your phone. Each private link works once and expires after five minutes.

Connect GitHub and a coding model

Under GitHub CLI, choose Sign in with GitHub. Open GitHub and authorize the displayed device code. Use Check connection to verify that the CLI is ready. The connection stays in T3’s persistent home.

Use Coding accounts and harnesses to connect an eligible ChatGPT or Claude subscription. To use your own GPU, load a local language model, open Use Xur models in T3 and choose the served model, harness and context limit. Connect to T3 checks that the model can complete a tool call.

Choose where commands run

DinD gives the project a Docker-in-Docker environment. Host uses the host’s tools and the service user’s file access. Finish active commands before choosing Apply runtime. T3 restarts briefly, keeping the same projects, accounts and device pairings.

To let a coding agent inspect Xur, open Permissions and storage and enable Read Xur data. Save, then choose Connect or repair Xur MCP and start a new thread. Grant write access only when you want the agent to change settings or run actions. Full host access grants root commands on the server.

For runtime details, private networking and permissions, read the T3 Code reference.
