Run local AI on the PC you game on.

Xur is an open-source operating system for GPU PCs, built on Bazzite. A profile remembers which GPUs run your desktops and models. Switch jobs on one card from your browser, or give each job its own GPU and run both at once.

Pick up the same coding project on your phone.

T3 Code keeps your projects and sessions on the server while you switch GPU profiles. Pair the T3 app on your laptop or phone to open the same environment on either device.

Connect GitHub CLI with a device code, bring a coding subscription, or choose a compatible model running on Xur.

Take your gaming desktop to the TV.

Leave the GPU in your PC. Play at its monitor or stream the desktop to a Moonlight client. A named workstation keeps its files, Steam login and pairing when you move it to another GPU.

Find out how a model runs on your hardware.

Load a language model, try a prompt in Model lab, then benchmark it. Saved results keep the responses, timing and GPU memory readings together so you can compare configurations later.

Copy the ready endpoint into an OpenAI-compatible client, or add an audio.cpp workload for speech synthesis and transcription.

Use a dataset straight from your NAS.

Connect a network folder once, then assign it to the models and containers that need it. Give an inference workload read-only access while keeping a single copy of the dataset on your file server.

You can also share an existing folder on the Xur PC with selected clients over encrypted SMB3.

Before you install

Start with an x86-64 UEFI PC, internet access and a target disk of at least 64 GiB. Installation erases the selected disk.

Xur is in preview. The project has tested a single gaming workstation with Moonlight on RTX 3090 hardware. Testing continues on peripheral isolation between simultaneous desktops.
