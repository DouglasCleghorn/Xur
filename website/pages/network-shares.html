Give a workload a folder from your NAS.

Keep a dataset in one place. Xur can mount an SMB3 share from your file server and make it available to selected containers and model workloads.

Connect the share

  1. Open Storage → Network shares. Under SMB runtime, install the runtime if needed. The installation requires internet access.
  2. Choose Add connection. Enter a name, the server and share, the SMB credentials, and the local user and group IDs that should have access. Read-only access and required encryption are selected by default.
  3. Save, then choose Connect. Use Test access to check both the SMB login and filesystem access.

Assign it to a workload

Edit a model or container in Profiles. Expand Shared network folders, select the connection and save. Load the profile. The folder appears at the displayed /shared/… path inside that workload. To allow writes, both the connection and its workload assignment must permit them.

Xur checks required shares when the workload starts. If the NAS is unavailable, startup reports the problem. Unload workloads using a share before disconnecting or removing it.

Share a folder from the Xur PC

Under Hosted here, choose an existing local data folder. Set a dedicated SMB account, the filesystem user and group IDs, and the client IPv4 addresses or subnets allowed to connect. A blank allowed-systems list denies access.

Choose the host’s LAN or VPN address and start hosting. Clients use the displayed connection address and the share’s credentials. Hosting continues across GPU profile changes. See the network shares reference for supported folders, permissions and backup details.
