Make a USB installer with Rufus

You need a Windows computer, Rufus from rufus.ie, and a USB drive large enough for the ISO. Use a drive of at least 16 GB; check the download size above.

The USB drive will be erased. Copy off anything you need and double-check which drive Rufus selects. Installing Xur later also erases the host disk you choose.

  1. Download the ISO and open Rufus.

    Rufus runs without installation. Wait for the ISO download to finish; do not select an app update archive or an ISO part.

  2. Select your USB drive.

    Under Device, pick the USB drive. Under Boot selection, choose Disk or ISO image, click SELECT, and open the downloaded .iso file. Its name includes stable or nightly and the version.

  3. Choose UEFI settings.

    Use GPT, UEFI (non CSM), and FAT32. Click START. If asked, choose ISO Image mode. Confirm erasing the USB drive and wait for READY.

  4. Boot the host from USB.

    Safely eject the USB drive, connect it to your x86-64 GPU host, and select its UEFI entry in the boot menu. Keep Internet access available; wired Ethernet is the simplest setup.

  5. Install from the console, then create your account.

    Open Setup and installation on the host, save its name, configure networking, and select a target disk of at least 64 GiB. Review the erase plan and choose Yes to install. New installations use Btrfs root storage. After installation and reboot, open the displayed HTTPS address on port 8443, enter the console setup code and create the administrator account. Follow the getting-started guide for your first profile.

Verify the download or use another operating system

The release notes include the ISO checksum. Download xur-update.json from the same installer release to verify its signature and authenticated installer metadata. See the verification instructions. Ext4-root downloads and historical split media were retired; use current Btrfs media. Linux and macOS users can use a raw-image USB writer; see the USB media guide. Read the release notes for known limitations and tested hardware.
