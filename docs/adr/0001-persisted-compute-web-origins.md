# Persisted Compute browser trust boundary

Accepted on 2026-10-10. URL paths share a browser origin, so manager-origin paths are reserved for first-party Xur-maintained applications explicitly trusted as part of the manager; arbitrary or user-selected container frontends use separate hostnames, host-only credentials, and strict origin/antiforgery enforcement. This separates application content from privileged manager access and other applications at the cost of hostname and TLS provisioning; Q11 subsequently selects Tailscale for Xur-managed easy HTTPS custom-app URLs, with a distinct app origin and an Open button targeting the configured HTTP port; ordinary container port publishing and direct access remain available. LAN DNS/mDNS and local CA/custom TLS provisioning are outside this convenience feature, while existing local manager access and the trusted first-party `/robot` path remain available. Service naming, authentication, and tagged-host provisioning remain engineering work.
